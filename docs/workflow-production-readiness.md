Refreshed registry metadata: deepmerge latest **8.0.2**, stable. Prisma latest **8.0.0-rc.13**, next **8.0.0-rc.10**, prev **7.10.0**; a `latest` tag does not imply stable. No RC, downgrade, audit-force or dependency hiding used.

Release 8 adds cyclic-reference protection and fixes GHSA-ggr8-5vv4-36mx; breaking changes include deep Map-value merging, type helper renames, and deepmergeInto mutation fixes. Prisma's inspected call uses neither Map-specific behavior nor deepmergeInto/type helper APIs. v8.0.1 addresses TS7 types; v8.0.2 corrects the Node engine declaration. Nested ordinary config, arrays/undefined/null, shared graphs, recursive graphs, and real Prisma loading were exercised rather than inferring compatibility from audit alone. Release notes: https://github.com/RebeccaStevens/deepmerge-ts/releases/tag/v8.0.0 and v8.0.1/v8.0.2.
