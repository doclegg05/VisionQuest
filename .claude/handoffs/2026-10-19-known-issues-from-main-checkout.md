Program-document storage paths containing spaces, held in fields named `*Key`, trip `generic-api-key`. Verified false positives go in the repo-root `.gitleaksignore` by `file:rule:line` fingerprint, never by weakening the hook. Entries stop matching when a file's line numbers change

Commands that need those go into a prepared script run in the Terminal panel. Since 2026-10-16, `gh` and `git push` work when the Bash call is that one plain command (no cd, pipe or `git -C`), and a hook blocks plain pushes to main. Harness auto-memory holds the detail (`session-sandbox-blocks-push-and-live-evals`)
